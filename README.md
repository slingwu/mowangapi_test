#mowangapi_test

默往接口自动化测试项目
基于熟人社交的聊天业务场景，自主设计并实现一套接口自动化测试项目。
项目使用“python+pytest+Requests+YAML+FastAPI mock+Allure"搭建，覆盖登录、消息发送、多端同步、钱包转账等核心接口场景、并支持本地Mock拂去联调和测试报告生成。
----

##一.项目背景
默往是一款专为熟人好友打造的私密安全聊天软件，提供高效便捷、私密安全的沟通方式。
本项目以默往为业务背景，围绕聊天软件的核心模块，搭建了一套可执行、可扩展、可展示的接口自动化框架。

由于当前无法接入真实后端环境，项目采用的是''FastAPI Mock Server'的方式模拟接口服务，完成接口自动化测试设计和执行。

###四.核心能力
本项目重点实现了一下能力：

-基于'Pytest'完成了测试组织与执行
-使用'fixture'管理登录态、实现一次登录获取token，后续用例自动携带认证信息
-使用'YAML'实现测试数据驱动
-封装统一HTTP请求类、统一管理请求方法、请求头、日志输出
-基于'FastAPI'搭建本地Mock服务，模拟后端接口联调
-使用allure生成可视化测试报告
-通过GitHub管理项目源码，具备接入jekin的基础

##八.项目亮点

本项目的亮点主要包括：
-基于真实业务场景进行测试设计，而不是简单的demo脚本
-使用'mock'服务解决无真实接口环境下的自动化测试问题
-通过'fixture+token'实现接口认证自动化管理
-通过'YAML'实现测试数据与测试逻辑分离
-通过统一HTTP请求邓庄替身代码复用性与可维护性
-通过Allure报告提升测试结果可视化能力
-后续可接入Jenkins实现自动化持续执行
